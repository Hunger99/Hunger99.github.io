Publications

MemReward: Graph-Based Experience Memory for LLM Reward Prediction with Limited Labels

Tianyang Luo*, Tao Feng*, Zhigang Hua, Yan Xie, Shuang Yang, Ge Liu, Jiaxuan You

Conference on Neural Information Processing Systems. NeurIPS 2026

A graph-based experience memory that propagates rewards from labeled to unlabeled rollouts during online RL fine-tuning of LLMs. With ground-truth rewards on only 20% of rollouts, MemReward reaches 97.3% / 96.6% of fully supervised training (Oracle) on Qwen2.5-3B / 1.5B.

arXiv Project Page Code Dataset Meta Sponsored Research Project

ExpWeaver: LLM Agents Learn from Experience via Latent RAG

Tao Feng, Tianyang Luo, Jingjun Xu, Zhigang Hua, Yan Xie, Shuang Yang, Ge Liu, Jiaxuan You

International Conference on Machine Learning. ICML 2026

LLM agents learn from experience through latent retrieval-augmented generation: past experiences are encoded with the LLM's own hidden states and retrieved in latent space at every decoding step. ExpWeaver is best on 12 of 13 tasks, over 6.8% above the strongest baseline, with token cost close to non-retrieval baselines.

Projects

Agent Learning Flywheel: Improving a 180B Financial LLM Agent

ACM Club practicum project, Sep. 2026 - mid-Nov. 2026 (expected).

Designed a workflow for a 180B financial LLM agent that chooses one update per round from task failures: edit skill instructions, or generate verified tool-use records for LoRA supervised fine-tuning. The Claude Code harness, which manages tools and sessions, stays fixed; old and new versions are compared on identical tasks before retaining an update.
