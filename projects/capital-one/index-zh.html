摘要

本项目使用DocFinQA、IFEval、FinDeepResearch和合并的561题DS-1000 Python数据分析子集，比较Qwen3.5-4B-Base的九个训练设置。监督微调（SFT）学习经过验证的示范，DAPO从工具辅助试答与任务专属奖励中学习。DocFinQA负责金融长文档问答，FinDeepResearch负责投研报告，DS-1000子集覆盖基础数据处理、绘图与机器学习库调用。DS-1000的同源题去重、执行验收和训练切分尚未完成；新一轮训练尚未开始。

Settings

  • Base model: Qwen3.5-4B-Base。S0、S1 分别从相同权重独立开始；配对 DAPO 实验使用相同的起始检查点。
  • Teacher Model: Qwen3.8-27B 用于采集 SFT 示范轨迹。
  • 原题与评测: 执行训练的设置共用相同原题身份；九组共用同一份冻结的验证集和测试集，以及相同的工具条件和评分器版本。仅使用验证集选择检查点。
  • 新增数据: 所有 S1 后续设置共用同一份 SFT 新增题；所有 R1 设置共用另一份固定的 DAPO 新增题，不为不同候选重新生成。新增题池尚未冻结。

Harness

Harness 要素核心内容核心内容在我们这里如何实现
上下文管理提示工程、Agent 状态栏、上下文压缩、Agent Skills
  • 提示工程：按任务环境注入system、题面、输出要求及允许工具。
  • Agent 状态栏：H1（启用清单、约束检查、结果核验与有限纠错的运行配置）用set_checklist保存清单，并在工具结果后以文本回显完成标记。
  • 上下文压缩：-（未实现历史摘要或压缩；消息只追加，新工具结果按长度截取）。
  • Agent Skills：-（模型运行时未实现技能包加载与调用）。
上下文管理（跨会话）用户记忆、RAG、结构化索引、智能体化 RAG
  • 用户记忆：-（每次尝试独立初始化，未建立跨会话用户记忆库）。
  • RAG：DocFinQA检索并读取指定报告证据；仅在本任务内使用，不存储用户记忆。
  • 结构化索引：报告按编号分块、建立BM25索引，支持chunk_id及邻近段落读取；无跨会话个人知识索引。
  • 智能体化 RAG：模型可在任务内多次检索、读取和计算；跨会话知识更新为-（未实现记忆写入与更新协议）。
工具接口与约束工具分类、权限控制、MCP 标准、主动工具发现
  • 工具分类：按任务环境注册工具白名单和JSON参数格式，仅分派已知工具。
  • 权限控制：H1在声明的写操作前检查参数和规则；已有v2 Python适配器用bubblewrap隔离、只读挂载、断网及时间／内存限制，DS-1000尚未接入。
  • MCP 标准：-（当前直接注册函数工具，未接入MCP协议）。
  • 主动工具发现：-（工具列表在尝试开始时固定，未实现动态搜索或加载）。
验证与纠正Coding Agent 的 Harness、测试驱动、代码化规则
  • Coding Agent 的 Harness：模型→工具→真实返回→模型的循环及轨迹保存已实现；DS-1000代码补全适配尚未完成。
  • 测试驱动：-（已有离线测试与评分检查，未实现运行时先写测试、再驱动编码的流程）。
  • 代码化规则：H1核对清单、环境要求与结果依据；工具错误附有效调用示例，重复调用给出提示，拒绝结束后仅允许有限纠错。
